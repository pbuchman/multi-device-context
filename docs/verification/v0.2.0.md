# v0.2.0 acceptance

The v0.2 server and shared UI are deployed on home-dev. Tests cover automatic
titles, agent access, direct context navigation, fresh opening, preservation of
unsent drafts, automatic switching, and permanent deletion.

## Source and hosted evidence

- 151 Vitest tests and 8 runtime tests pass, with all workspace typechecks and
  production server/web builds. Tests include Google return targets, key UI,
  credential boundaries, rate limits, immutable writes, URL validation, draft
  preservation, interrupted renames and deletion-listener races.
- 18 Firestore/Storage emulator tests pass, including real Admin SDK persistence,
  key hashing/revocation, owner isolation, pagination, anti-resurrection markers,
  exact streamed bytes, and AI rename/delete races. Emulator-only integration is
  guarded against accidentally running against production.
- Playwright checks passed for the actual interface at desktop light/dark and
  narrow widths. The computer-use browser surface was unavailable, so standalone
  Playwright was used. Tests produced no browser console errors.
- Production Firestore rules and all required indexes were deployed and reached
  READY. The inference-only OpenRouter key is private with a USD 1 monthly cap.
  An actual ZDR-required `openai/gpt-4.1-nano` completion passed; the standalone
  synthetic probe cost USD 0.0000087. No credential or prompt was logged.
- Public CLI/API acceptance passed: create, watch, get, append, rename, upload,
  download with byte comparison, cross-account denial, permanent deletion and
  revocation (subsequent HTTP401). Two Chromium sessions with synthetic Firebase
  sessions exercised the actual ContextWorkspace, DurableOutbox and FirebaseCloud
  against live Firestore: first-share acknowledgement, immediate switching in
  both directions, preserved draft/code mode, and synchronized deletion.
- Live deletion testing exposed the parent/item-listener ordering race. The fix
  suppresses a permission error only after an authorized server read confirms the
  parent is absent/deleting; genuine errors remain visible. The live regression
  then passed. Synthetic accounts, contexts, files and agent keys were removed.
- The app-only restart passed host verification at 19:30:06 UTC on 30 September
  2026 at `4a73efcd97099d88ffdc7f49081d316d30b27859`. Public HTML and all five
  referenced assets matched the deployed files byte-for-byte. Caddy/cloudflared
  remained active and the existing 8790/8080/80 listeners remained present.
- The portable skill and CLI are installed under the home-dev user's agent skills
  directory. Each agent still needs its own privately configured user-created key.
  Merely installing the skill does not start a background agent.

## Data semantics

There is no application trash, content backup or restore API. Deleted context
IDs remain as markers to stop offline replay. Offline clients purge drafts and
pending shares on reconnection. Firestore PITR and bucket soft delete remain
disabled; Firestore still has unavoidable one-hour technical versions. Files
explicitly saved outside the app are independent copies. AI requests contain
bounded text or filename/type metadata, never attachment bytes.
